🔐 卡密后台管理系统

生成卡密 → AES-256-GCM 加密 + HMAC 签名 → 上传到 GitHub 云端 → 主软件联网验证。
云端只存卡密哈希，不存明文；卡密明文只在生成时展示，请及时导出保存。

① GitHub 云端配置

Token 生成路径：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 勾选你的仓库 → Repository permissions 里把 Contents 设为 Read and write。
